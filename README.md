# 거인 키 키우기 (Roblox)

음식을 주워 먹고, 우유 비를 쟁탈하고, 농구·철봉·침대로 키를 키워 **아바타가 진짜로 거인이 되는** 로블록스 시뮬레이터.

- 처음 설치: [docs/SETUP.md](docs/SETUP.md)
- 테스트 체크리스트: [docs/PLAYTEST.md](docs/PLAYTEST.md)
- 설계서 / 계획: `docs/superpowers/`

## 코인과 꾸미기 뽑기

몬스터·건물 부수기·보스·일일 미션으로 코인을 벌어요. 왼쪽 **상점**에서 100코인으로 날개·오라·발자국 상자를 열면
일반 70% · 희귀 25% · 전설 5%로 꾸미기가 나와요(중복이면 50코인 환급, 같은 상자 30번째는 전설 확정).
종류마다 하나씩 착용할 수 있고 몸이 커지면 같이 커져요. 숫자와 아이템은 `Config.COINS`, `Config.COSMETICS`.

## 10cm에서 거인까지, 건물 부수기

키 10cm, 개미만 한 몸으로 시작해요(150cm까지 몸도 같이 커짐). 점프해서 건물 옆에 착지하면 **내 키보다 낮은 건물**이
무너지고 키를 얻어요(건물 1층 = 3m, 한 번에 최대 3채). 무너진 건물은 60초 뒤 다시 생겨요. 숫자는 `Config.SMASH`.
큰길 상가는 글씨 대신 생김새(노래방·PC방·카페·치킨·편의점·약국·미용실·분식·학원·꽃집)로 알아볼 수 있어요.

## 펫과 몬스터

펫은 최대 3마리까지 팀으로 데리고 다녀요. 음식을 먹거나 몬스터를 잡으면 경험치가 오르고, 15·35레벨에 진화해요.
구역마다 야생 몬스터(시장 비둘기, 양근천 오리, 두물머리 잉어·왜가리, 용문산 멧돼지·까마귀, 별똥별 정령)가 돌아다니고,
펫이 자동으로 싸워요. 몬스터를 터치하면 집중 공격, 펫 카드의 버튼은 필살기, 높이서 떨어져 착지하면 밟기.
잡은 몬스터는 가끔 길들일 수 있고, 보스를 잡으면 보스 펫을 받아요. 숫자는 `src/shared/Config.luau`의
`PET`, `PET_SPECIES`, `MONSTER`에 있어요.
