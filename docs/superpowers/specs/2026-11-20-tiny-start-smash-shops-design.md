# 10cm 시작 · 건물 부수기 · 생김새로 알아보는 가게 — 설계

날짜: 2026-11-20 · 상태: 승인 대기

## 의도와 이유

- **10cm 시작**: 개미만 한 크기로 진짜 양평 거리를 돌아다니다 거인이 되는, "작음 → 거대함"의 차이를 크게 느끼게 한다.
- **건물 부수기**: 거인이 된 느낌을 손으로 확인하게 하고, 키가 클수록 더 큰 건물을 부술 수 있어 다음 목표가 계속 보이게 한다(단독주택 → 상가 → 아파트 → 오스타 코아루). 부수면 키가 커서 성장 방법도 된다.
- **가게 생김새**: 글씨 간판 대신 노래방은 노래방처럼, PC방은 PC방처럼 생겨서 거리가 살아 보이게 한다.

## 목표

1. 시작 키 10cm, 150cm 미만이면 몸도 작아진다.
2. 착지(밟기)로 건물을 부순다. 내 키(cm) > 건물 키(층수 × 3m)일 때만. 부수면 키 보상.
3. 부서진 건물은 무너지는 연출 → 돌무더기 → 60초 뒤 원래대로.
4. 상가 1층(과 일부 위층)이 글씨 없이 가게 종류별 생김새를 가진다.

## 하지 않는 것

- 진짜 물리로 조각조각 무너지는 건물(사용자가 ①을 골랐다).
- 양평역·정류장·시장 아케이드·로터리 부수기.
- 랜드마크 이름(양평역, 시장1길 문, 오스타 코아루 이름판)의 글씨 제거 — 실제 간판 이름이라 유지.

## 실패로 치는 것

- 여러 채를 연달아 부술 때 폰이 버벅인다.
- 부서진 건물이 다시 안 생기거나, 반쯤만 돌아온다(투명한 벽, 안 보이는데 막힘 등).
- 10cm 캐릭터가 조작 불가능할 만큼 작거나, 카메라가 땅속으로 들어간다.
- 기존 저장(키 150cm 이상인 사람)이 영향을 받는다.

## 제약

- 숫자는 `Config`. 계산은 순수 Logic 모듈 + luau 테스트. 서버 권한.
- 맵은 genmap → BaseMap.rbxm. 1구역 파트 예산은 현재 13,000(사용 약 12,350). 가게 장식으로 늘어나면 **15,000까지만** 올리고, 넘으면 장식을 줄인다.
- 기존 밟기 리모트 `Stomp`(펫 전투)를 같이 쓴다.

## 접근 방식

| | 방식 | 장점 | 단점 |
|---|---|---|---|
| **① (선택)** | 서버가 건물을 숨기고(투명·통과), 클라이언트가 잔해 조각·먼지 연출, 돌무더기 남김, 60초 뒤 복구 | 가볍다, 여러 채 동시 OK | 진짜 물리 붕괴는 아님 |
| ② | 건물 파트를 풀어 물리로 무너뜨림 | 가장 실감 | 서버·폰 렉, 복구 복잡 |
| ③ | 미리 만든 폐허 모형으로 교체 | 보기 좋음 | 파트 2배, 예산 초과 |

## 사용자가 정한 것

- 시작 키 10cm.
- 부수면 키 보상, **건물보다 키가 커야** 부술 수 있음, 비교는 cm(건물 1층 = 3m) — 제안을 받아들임.
- 부수는 방법: **밟기(착지)로만**.
- 건물 숨기기 + 연출 방식 ①.
- 가게: 글씨 대신 생김새(아래 목록 확인함).

## 설계 (Claude의 제안은 *표시*)

### 1. 10cm 시작
- `Config.START_HEIGHT = 10`.
- `Growth.heightToScale`: 150cm 미만이면 *`(h/150)^0.45`* (10cm ≈ 0.30, 150cm = 1로 이어짐). 150cm 이상은 지금 공식 그대로.
- 이동은 기존 `moveStats(scale)`가 따라감(10cm: 걷기 약 8.7, 점프 약 27). 카메라 최소 거리는 작을 때 0.5 유지.
- 저장된 키가 있는 사람은 그대로. 새 사람·환생만 10cm에서 시작.

### 2. 건물 부수기
- **맵**: genmap이 건물마다 `Model`(이름 `Building_<id>`)으로 묶는다. 속성 `Floors`, `HeightCm = Floors × 300`, 태그 `Breakable`. 오스타 코아루 이름판 파트도 그 건물 모델에 넣는다. 랜드마크(역·정류장·시장·로터리)는 태그 없음.
- **판정** (Logic `Smash`): 착지 위치(발)에서 수평 거리 `≤ 건물 반지름 + 3·scale` 안의 건물 중 `HeightCm < 내 키`인 것을 부순다. *한 번 착지에 최대 3채.* 키가 모자란 건물이 있으면 *"건물 12m — 키가 더 커야 해요!"* 안내(같은 건물 안내는 5초에 한 번).
- **보상**: *`Zones.bestGain(구역) × Floors × 5`*, 소스 `"smash"`(음식 미션·펫 음식 경험치에 안 섞이게 `Quests` 특수 소스에 추가).
- **연출**: 서버는 건물 파트를 `Transparency=1, CanCollide=false, CanQuery=false`로 바꾸고(원래 값은 속성에 저장), SurfaceGui 끔, 바닥에 건물 색 *돌무더기 3조각*(앵커). 모든 클라이언트에 `BuildingBroken(위치, 크기, 색)` → 클라이언트가 *잔해 8조각*을 튀겨 2초 뒤 지우고 먼지 파티클·흔들림·소리.
- **복구**: *60초* 뒤 돌무더기 삭제, 원래 값 복구. 그 사이엔 다시 부술 수 없다. 복구 자리에 플레이어가 서 있으면 *복구를 3초씩 미룬다*(몸이 건물에 박히지 않게).

### 3. 생김새로 알아보는 가게
- 1층 가게 칸마다 종류를 정하고 글씨 대신 장식을 붙인다. 유리는 벽에서 *1.6스터드* 앞으로 내고 반투명, 유리와 벽 사이에 가게 안 물건을 둔다.
- 종류와 생김새(사용자 확인함):
  - 노래방: 보라·분홍 네온 테두리, 미러볼, 마이크 장식
  - PC방: 어두운 유리 안 파란 모니터 줄, 의자, 파란 LED 띠
  - 카페: 나무 외벽, 앞 테이블·파라솔, 큰 컵 장식
  - 치킨집: 빨강·노랑 차양, 닭다리 장식, 테이블
  - 편의점: 흰 외벽·초록/파랑 띠, 진열대 줄
  - 약국: 초록 네온 십자가
  - 미용실: 빨강·하양·파랑 줄무늬 기둥
  - 분식·식당: 김 나는 솥, 빨간 등, 테이블
  - 학원: 칠판과 책상 줄
  - 꽃집·과일가게: 앞에 화분·과일 상자
- 위층: 글씨 간판 대신 *노래방은 분홍 네온 창틀, PC방은 파란 빛 창* 같은 색 창(파트 1개).
- 모서리 세로 간판(글씨)은 없앤다. *시장 아케이드 안의 작은 가게 간판도 같은 방식으로 바꾼다*(글씨 → 가게 물건).
- 파트 예산: 멀리 있는 작은 가게는 장식 수를 줄여 15,000 안에 맞춘다.

## 만드는 사람에게 맡기는 것

장식의 정확한 모양·색, 잔해 연출 세부, 수치 미세 조정.

## 확인 방법

- Logic 테스트: `heightToScale`(10cm ≈ 0.30, 150cm = 1, 연속), 부수기 판정(키 비교·거리·최대 3채·복구 대기), 보상 계산.
- 맵 테스트: 모든 일반 건물이 `Building_<id>` 모델·`Breakable` 태그·`HeightCm` 속성을 가짐, 랜드마크엔 태그 없음, 건물 라벨에 글씨 없음(랜드마크 제외), 파트 수 ≤ 15,000.
- Studio 플레이 테스트(MCP): 10cm로 시작, 작은 건물 밟아 부숴짐·보상·60초 뒤 복구, 키 모자라면 안내, 콘솔 에러 없음, 가게 생김새 스크린샷.
