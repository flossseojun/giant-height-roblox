# 펫 고도화: 키우기 + 몬스터 전투 — 설계

날짜: 2026-11-20 · 상태: 승인 대기

## 의도와 이유

플레이해 보니 두 가지가 부족했다: (1) 혼자 할 때 쫓아갈 목표가 없고, (3) 금방 질린다.
펫을 **키우는 재미**와 **싸우는 재미**를 더해서, 양평 곳곳을 돌아다니며 몬스터를 잡고 펫을 키우고
모으는 것이 그 자체로 목표가 되게 한다. 이번 작업은 4개 프로젝트(펫 → 코인·꾸미기 상점 → 양평 도감·스탬프 →
업적 사다리) 중 첫 번째이며, 이후 프로젝트의 보상(펫, 경험치)을 받을 틀이 된다.

## 목표

- 펫이 경험치를 얻어 레벨이 오르고, 정해진 레벨에서 진화한다(모습·크기 변화).
- 구역마다 야생 몬스터가 돌아다니고, 펫이 싸운다. 플레이어는 거든다(집중 공격, 필살기, 밟기).
- 몬스터를 이기면 확률로 길들여 새 펫을 얻는다. 보스를 잡으면 희귀 펫을 얻는다.
- 펫은 최대 3마리까지 팀으로 데리고 다닌다.
- 기존 보스전에 펫이 함께 싸운다.

## 하지 않는 것 (이번엔)

- 친구 펫과의 대결(PvP) — 나중에 이 전투 위에 얹는다.
- 코인, 상점, 도감, 업적 — 다음 프로젝트들. 이번엔 몬스터 보상이 펫 경험치 + 키다(코인 훅 자리만 둔다).

## 실패로 치는 것 (안티 목표)

- 몬스터가 **플레이어를** 때리거나 멈추게 하는 것 (사용자가 보스 기절을 싫어했다).
- 폰에서 버벅이는 것 (맵 파트가 이미 약 12,000개).
- 기존 저장(키, 고른 펫)이 사라지는 것.
- 펫 때문에 키 성장이 지나치게 빨라져 기존 균형이 깨지는 것.

## 제약

- Luau, Rojo(스크립트만 동기화), 서버 권한. 숫자는 전부 `Config`.
- 계산은 순수 `Logic` 모듈로 떼어 `luau` 테스트(tests/run.luau)로 검증한다.
- 맵 데이터(몬스터 출현 지점)는 `tools/genmap.py` → `BaseMap.rbxm`에 태그로 넣는다. 1구역 파트 예산 13,000.
- 몬스터 모델은 실행 중에 서버가 만든다(맵 예산 밖). 대신 동시에 살아 있는 몬스터 수에 상한을 둔다.
- DataStore 저장은 `DataService.extra(player)`에 붙인다.

## 접근 방식

| | 방식 | 장점 | 단점 |
|---|---|---|---|
| **① (선택)** | 기존 펫 코드 확장 + 파트로 만든 가벼운 몬스터, 서버가 출현 지점 반경 안에서 움직임 | 수십 마리여도 가벼움, 기존 구조와 맞음, 양평 곳곳에서 만남 | 길 찾기 없음(반경 안 배회) |
| ② | Humanoid NPC + 길 찾기 | 가장 자연스러움 | 1만 파트 맵에서 무거움, 복잡 |
| ③ | 구역별 울타리 사냥터 | 가장 간단 | 시내를 돌며 만나는 재미 없음 |

사용자가 ①을 골랐다.

## 사용자가 정한 것

- 키우기 + 싸우기, 상대는 **몬스터(PvE)**.
- 전투 조작 **②**: 기본 공격 자동, 몬스터 터치 시 집중 공격, 펫마다 필살기 1개(쿨타임), 거인 밟기(키 클수록 셈).
- 기존 보스전에 펫 참여.
- 획득 **ⓐ**: 몬스터 처치 시 확률 길들이기, 보스 → 희귀 펫, 고양이·수달·다람쥐는 키 해금 유지.
- 팀 최대 3마리.

## 설계 (Claude의 제안은 *표시*)

### 펫 종류
`Config.PET_SPECIES`: id, 이름, 진화 3단계 이름, 기본 공격력/체력, 필살기, 얻는 법(`height`/`tame`/`boss`), 구역.

| 구역 | 키 해금 | 길들이기 | 보스 펫 |
|---|---|---|---|
| 1 양평읍 | 시장 고양이 | 시장 비둘기, 양근천 오리 | 미니 호떡 |
| 2 두물머리 | 남한강 수달 | 두물머리 잉어, 왜가리 | 미니 메기 |
| 3 용문산 | 용문산 다람쥐 | 멧돼지, 까마귀 | 미니 구름 용 |
| 4 밤하늘 | — | 별똥별 정령 | — |

*몬스터 종류와 이름은 Claude 제안, 사용자 확인함("ㄱㄱ").*

### 키우기
- 경험치: 내가 음식을 먹을 때 팀 펫 전원 +XP(구역 배율 반영), 몬스터를 잡으면 그 전투에 참여한 펫 +XP.
- *레벨 곡선 `xpToNext(L) = round(10·L^1.5)`, 최대 50. 진화: 15레벨, 35레벨 (3단계).*
- *능력치: `stat = base · (1 + 0.12·(L−1)) · 진화배율(1, 1.5, 2.2)`.*
- 성장 배율·줍기 범위: *팀에서 가장 좋은 펫 기준* `mult = base + 0.01·L`, `radius = base · (1 + 0.02·L)`.
  → 3마리를 데려가도 배율이 곱해지지 않아 키 성장 균형 유지(안티 목표).

### 전투
- 서버 전투 틱 *0.25초*. 펫은 주인 주변에 있다고 보고, 주인 기준 사거리 안 몬스터를 공격.
- 집중 공격: 클라이언트가 몬스터를 터치 → `FocusMonster` 리모트 → 사거리 *2배*까지 그 몬스터 우선.
- 기본 공격: 살아 있는 펫마다 *1초*에 한 번 공격력만큼.
- 필살기(펫마다 1개, 쿨타임 *12~20초*): *연타(단일 5배)*, *광역(반경 10, 2배)*, *회복(팀 체력 40%)* 세 유형 중 하나. HUD에 팀 펫마다 버튼.
- 거인 밟기: 착지할 때 주변(*3·scale 스터드*) 몬스터에 `BossFight.damageFor(scale)`와 같은 공식의 데미지.
- 몬스터는 **펫만** 공격한다. 펫 체력 0 → 기절 *10초* 뒤 회복, 벌칙 없음.
- 몬스터 보상: 펫 XP + 키(`Zones.bestGain × 몬스터 배율`). *코인은 다음 프로젝트에서 같은 지점에 붙인다.*

### 길들이기
- 몬스터 처치 시 종마다 확률(*흔함 8%, 드묾 3%*)로 마지막 타격 플레이어에게 "길들이기!" 버튼 *8초*.
- 누르면 레벨 1 펫으로 보유 목록에 추가. *보유 최대 30마리*(넘으면 안내).
- 보스 처치에 참여하면 그 보스 펫을 *처음 한 번* 확정 지급.

### 몬스터
- 맵에 `MonsterSpawn` 태그 파트(속성 Zone, Species, Radius). genmap이 OSM에서 뽑는다:
  1구역 비둘기 = 시장 골목·역 광장, 오리 = 양근천 물가. 2~4구역은 각 구역 안.
- 지점마다 살아 있는 몬스터 *최대 3*, 처치 후 *20초* 뒤 다시 나옴. *구역당 동시 상한 1구역 24, 나머지 12.*
- 모델: 서버가 파트로 만든 동글동글 모델(앵커), 반경 안을 CFrame 보간으로 배회, 머리 위 체력바.
- 건물 안에 출현 지점이 생기면 안 된다(테스트).

### 보스전
- 팀 펫이 있는 플레이어가 보스 근처에 있으면 펫 공격이 보스 체력을 깎는다(기존 `BossFight.hit` 사용).
- 보스 공격은 여전히 플레이어를 멈추게 하지 않는다.

### 화면 (UI)
- 펫 창 개편: 보유 목록(레벨 막대, 진화 단계), 팀 칸 3개, 넣기/빼기.
- HUD: 팀 펫 체력바 + 필살기 버튼, 길들이기 버튼, 레벨업·진화 알림.
- 펫 모습: 플레이어마다 최대 3마리가 따라다니고, 진화할수록 커지며, 싸울 땐 목표 몬스터 쪽으로 달려가는 연출(클라이언트).

### 저장
- `extra.pets = { owned = { {uid, kind, level, xp} }, team = {uid…}, nextId }`.
- 이전 저장 변환: `extra.pet`만 있으면 → 키로 열린 펫들을 레벨 1로 보유에 넣고 팀 = {예전 펫}.
- *환생해도 펫은 유지.*

## 만드는 사람에게 맡기는 것

정확한 수치 조정, 몬스터·진화 모습, 필살기 이름, UI 배치 세부, 몬스터 배회 연출.

## 확인 방법

- Logic 테스트: 레벨 곡선·진화·능력치, 전투(데미지·기절·회복), 길들이기 확률, 저장 변환, 팀 배율이 곱해지지 않음.
- 맵 테스트: MonsterSpawn이 구역별로 있고 건물·물 안에 없음, 1구역 예산 유지.
- Studio 플레이 테스트(MCP): 몬스터 출현, 펫 공격, 밟기, 길들이기, 보스전 펫 참여, 콘솔 에러 없음.
