# 코인 + 꾸미기 뽑기(날개·오라·발자국) — 설계

날짜: 2026-11-20 · 상태: 승인 대기 · 3개 프로젝트(상점 → 양평 도감 → 업적) 중 첫 번째

## 의도와 이유

혼자 할 때도 쫓아갈 목표를 주고(코인 모으기 → 뽑기), 친구들이 보고 "오 그거 뭐야?" 할 자랑거리(날개·오라·발자국)를 만든다.
다음 프로젝트(도감, 업적)의 보상(코인)을 받을 곳이 된다.

## 목표

1. 코인: 몬스터·건물 부수기·보스·일일 미션으로 번다. 나중에 도감·업적도 코인을 준다.
2. 종류별 뽑기 상자(날개 / 오라 / 발자국)를 코인으로 연다.
3. 뽑은 꾸미기를 종류마다 하나씩 동시에 착용한다. 몸이 커지면 꾸미기도 커진다.

## 하지 않는 것

- 로블록스 유료 결제(로벅스), 카탈로그 에셋.
- 꾸미기 사고팔기·선물.
- 펫 꾸미기.

## 실패로 치는 것

- 코인이 순식간에 쌓이거나 너무 안 쌓여서 뽑기가 의미 없어진다.
- 클라이언트가 코인·뽑기 결과를 조작할 수 있다(서버가 굴림).
- 거인 + 발자국이 렉을 만든다.
- 기존 저장이 깨진다.

## 제약

- 숫자는 `Config`, 계산은 순수 Logic 모듈 + luau 테스트, 서버 권한.
- 저장은 `DataService.extra(player)`.
- 꾸미기는 각자 화면에서 그린다(펫과 같은 방식) — 서버는 착용 정보만 속성으로 알린다.

## 접근 방식

| | 방식 | 장점 | 단점 |
|---|---|---|---|
| ① | 서버가 캐릭터에 파트·효과를 붙임 | 크기 자동 | 리스폰마다 다시, 발자국은 서버에 무거움 |
| **② (선택)** | 서버는 착용 정보만, 각자 화면에서 그림 | 서버 가벼움, 발자국 부드러움, 펫에서 검증 | 크기 맞추는 코드 직접 |
| ③ | 로블록스 카탈로그 아이템 | 모양 예쁨 | 에셋 승인 문제(효과음에서 겪음), 수정 불가 |

## 사용자가 정한 것

- 꾸미기 종류: 날개, 오라, 발자국.
- 얻는 법: **코인으로 랜덤 상자 뽑기**.
- 뽑기 규칙(제안을 받아들임): 종류별 상자, 일반 70% / 희귀 25% / 전설 5%, 중복이면 상자값 절반 돌려줌, 같은 상자 30번째 전설 확정(천장), 전설은 서버 전체 알림, 상자 여는 연출.
- 보여주는 방식 ②.

## 설계 (Claude의 제안은 *표시*)

### 아이템 *(종류마다 5개: 일반 2, 희귀 2, 전설 1 → 총 15개)*
| 종류 | 일반 | 희귀 | 전설 |
|---|---|---|---|
| 날개 | 참새 날개, 종이학 날개 | 나비 날개, 잠자리 날개 | 별빛 날개 |
| 오라 | 반짝이, 비눗방울 | 물방울, 단풍잎 | 남한강 물결 오라 |
| 발자국 | 흙 발자국, 눈 발자국 | 꽃잎 발자국, 별 발자국 | 불꽃 발자국 |

### 코인 *(수치는 Config, 플레이 테스트로 조정)*
- 몬스터 처치(마지막 타격): *2 × 구역 번호*
- 건물 부수기: *층수 × 1*
- 보스 처치 보상을 받을 때: *50 × 구역 번호*
- 일일 미션 하나 완료 *20*, 세 개 다 완료 보너스 *50*
- 상자 가격 *100*, 중복 환급 *50*
- 화면 오른쪽 위에 코인 수 표시, 벌 때 "+N 코인" 떠오름

### 뽑기 (Logic `Gacha`)
- 서버가 난수로 굴린다. 천장: 그 상자의 연속 비전설 횟수가 29면 다음은 전설 확정, 전설이 나오면 0으로.
- 결과: 새 아이템이면 보유에 추가(처음 얻은 거면 그 종류 자동 착용 *빈칸일 때만*), 중복이면 환급.
- 코인이 모자라면 안내만.

### 착용
- 상점 창에 종류별 탭: 보유한 꾸미기 목록, 눌러서 착용 / 다시 눌러서 해제.
- 플레이어 속성 `Cosmetics`(JSON `{wing, aura, trail}`)로 모두에게 알림.

### 그리기 (클라이언트 `Cosmetics`)
- 날개: 등 뒤에 파트 2~4개, 천천히 파닥임, 전설은 네온.
- 오라: 몸 주변 ParticleEmitter(색·모양 아이템별), 전설은 더 많고 빛남.
- 발자국: 걸은 거리가 *보폭(2 × scale)*마다 땅에 납작한 파트 하나, *3초 뒤 사라짐*, 플레이어당 동시 *최대 20개*.
- 모두 몸 크기(scale)에 맞춰 커짐.

### 화면
- 왼쪽 버튼 줄에 **상점**(펫·환생·미션 아래).
- 상점 창: 상자 3개(종류·가격·확률·천장까지 남은 횟수), 열기 버튼, 착용 탭.
- 상자 열기 연출: 빙글빙글 → 등급 색으로 번쩍 → 아이템 이름. 전설이면 서버 전체 알림.

### 저장
`extra.coins = number`, `extra.cosmetics = { owned = {[id]=true}, equipped = {wing?, aura?, trail?}, pity = {wing=n, aura=n, trail=n} }`. 없으면 0·빈 값으로 시작. 잘못된 id는 버린다.

## 만드는 사람에게 맡기는 것

꾸미기 모양·색·파티클 세부, 연출 타이밍, UI 배치 세부.

## 확인 방법

- Logic 테스트: 확률 경계(0.69/0.70/0.95), 천장(30번째 전설, 리셋), 중복 환급, 코인 부족, 저장 정리(잘못된 id 제거), 코인 계산.
- Studio(MCP): 코인 벌기·표시, 상자 열기·연출, 착용 시 날개·오라·발자국이 보이고 커짐, 콘솔 에러 없음.
