# 로블록스 "거인 키 키우기" 시뮬레이터 설계서

작성일: 2026-11-18 · 만드는 사람: 염서준 + Claude

## 1. 무엇을, 왜 만드나

- 웹으로 만든 "키 키우기"를 로블록스 버전으로 새로 만든다.
- 로블록스로 만드는 이유: 친구들이 **같은 서버에서 아바타로 만나고**, 키가 숫자가 아니라 **실제 몸 크기**로 보이기 때문. 친구 옆에 서서 내려다보는 순간이 이 게임의 핵심 재미.
- 분위기: 웹 버전처럼 귀엽고 과장되게. "키 크려면 이거 해라" 밈을 게임 요소로 쓴다.

## 2. 목표 / 하지 않을 것 / 실패 조건

**목표**
- 친구들이 같은 서버에서 키를 키우며 경쟁하고, 크기 차이를 눈으로 자랑한다.
- 키가 클수록 새 구역이 열리고, 새 구역에서 더 잘 클 수 있다.
- 접속을 끊어도 키가 저장되어 이어서 한다.

**하지 않을 것 (이번 범위 밖)**
- 유료 아이템(로벅스 판매), 거래 기능
- 플레이어끼리 밀치기·키 뺏기 같은 대결 (나중에 구역 하나로 추가할 수 있음)

**실패 조건 (돌아가도 실패인 경우)**
- 꾸미기·보조 요소가 실제 효과 없이 장식뿐일 때 (웹 버전 피드백)
- 보스가 너무 쉬울 때 (웹 버전 피드백)
- 다들 한자리에서 같은 것만 반복할 때 (맵을 돌아다닐 이유가 없을 때)

## 3. 정한 것 (서준이 결정)

- 장르: 거인 경쟁. 키 = 아바타 실제 크기, 키 조건 문으로 구역이 열림.
- 키우는 기본 방식: **맵에서 성장 음식 줍기** (제자리 클릭 방식 아님)
- 성장 방법 8가지 모두 넣기
  1. 성장 음식 줍기 – 구역마다 음식이 다르고, 가끔 희귀 황금 우유
  2. 우유 비 이벤트 – 몇 분마다 서버 알림 후 한 곳에 우유가 쏟아짐
  3. 농구 골대 – 공을 넣으면 성장, 키가 클수록 넣기 쉬움
  4. 철봉 매달리기 – 버티며 키 연타, 오래 버틸수록 성장
  5. 침대에서 자기 – 누워 있으면 천천히 성장 (방치용)
  6. 펫 – 따라다니며 음식 대신 줍기 / 성장 보너스
  7. 구역 보스 – 이기면 큰 성장 보상, 쉽게 깨지지 않게
  8. 하이파이브 – 친구와 하면 둘 다 잠깐 성장 속도 증가
- 만드는 방식: **깃허브 저장소 + Rojo로 스튜디오에 연동** (방식 B)

## 4. 만드는 방법 비교 (Approaches)

| 방식 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 복붙 | 스크립트를 하나씩 스튜디오에 붙여 넣기 | 설치 없음, 구조 배우기 좋음 | 스크립트 20개↑면 관리 어려움, Claude가 현재 코드를 못 봄 |
| **B. 깃허브 + Rojo (선택)** | Claude가 저장소에 파일로 작성 → Rojo가 스튜디오에 동기화 | 커져도 정리됨, 여러 파일 한 번에 수정, 버전 되돌리기 | 처음 설치 30분~1시간 |
| C. 게임 파일 받기 | 스크립트+기본 맵이 든 .rbxlx 파일 | 가장 빨리 돌아가는 걸 봄 | 맵 꾸민 뒤엔 덮어쓰기 불가 → 결국 A/B로 가야 함 |

선택 이유: 8개 기능 + 2차 업데이트까지 생각하면 처음 설치 비용보다 이후 관리가 훨씬 중요하고, 서준이가 이미 깃허브(flossseojun)를 쓰고 있음.

## 5. 단계 나누기

- **1차 (기본판):** 음식 줍기, 우유 비, 농구 골대, 철봉, 침대, 구역 문, 키 저장, 리더보드
- **2차 (업데이트):** 펫, 구역 보스, 하이파이브 – 1차 반응을 보고 다듬어서 추가

## 6. Claude가 정한 것 (고쳐도 됨)

- **키 단위와 몸 크기:** 키는 cm로 표시, 시작 150cm. 숫자는 계속 크게 오르지만 몸 크기는 천천히 커지게(로그 비례) 해서 맵을 뚫고 나가지 않게 함. 몸 크기 상한을 둠.
- **크면 같이 바뀌는 것:** 걷는 속도·점프 높이·카메라 거리를 몸 크기에 맞춰 조정해서 거인이 돼도 조작감이 자연스럽게.
- **구역 수 (1차):** 3개 구역 – ① 동네 놀이터 ② 학교 운동장 ③ 구름 위. 구역마다 음식 종류와 키 조건이 다름. 숫자 밸런스는 테스트하면서 조정.
- **배치:** 농구 골대·철봉·침대는 1구역부터 있고, 다음 구역일수록 보상이 큼.
- **저장:** 로블록스 DataStore로 키(와 2차의 펫 등) 저장. 저장은 게임을 Publish하고 "API 서비스 접근 허용"을 켜야 스튜디오에서도 작동.
- **리더보드:** 서버 안 순위(머리 위 키 표시 + 오른쪽 위 목록)와 전체 서버 역대 순위 보드(맵에 세운 판) 둘 다.
- **모바일 지원:** 철봉 연타 등 키 입력은 폰에서는 화면 버튼으로도 되게.
- **화면 글자:** 한국어.
- **저장소:** 깃허브 flossseojun 계정에 새 저장소 (이름 예: `giant-height-roblox`).
- **맵 꾸미기:** 기본 지형·구역 경계·문·시설 자리는 코드/파일로 만들어 두고, 예쁘게 꾸미는 건 서준이가 스튜디오에서 직접.

## 7. 제약

- Claude는 로블록스를 실행할 수 없어 직접 테스트 불가 → 서준이가 스튜디오에서 플레이 후 Output 창 에러·스크린샷을 보내 주는 방식으로 함께 고침.
- 서준이 컴퓨터에 VS Code, Rojo(VS Code 확장 + 스튜디오 플러그인), 로블록스 스튜디오 설치 필요.

## 8. 만드는 사람에게 맡기는 것

- 스크립트 폴더 구조, 서버/클라이언트 나누기, 숫자 밸런스 초기값
- 보스 공격 패턴의 구체적 형태 (2차 설계 때 서준이와 다시 정함)
- 펫 종류·외형 (2차 설계 때 서준이와 다시 정함)
