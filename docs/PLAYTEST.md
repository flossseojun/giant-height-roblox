# 스튜디오 확인 체크리스트

Claude는 로블록스를 직접 실행할 수 없어서, 여기 있는 건 서준이가 스튜디오에서 확인해 줘야 해.
안 되는 게 있으면 번호와 Output 창 빨간 글자를 같이 보내 줘.

## 1. 연결
- [ ] 1-1 Play 하면 Output에 "서버 시작", "클라 시작" 두 줄이 나온다

## 2. 키 · 몸 크기 · 저장
- [ ] 2-1 화면 위 가운데에 "150cm"와 "양평읍 시내"가 보인다
- [ ] 2-2 왼쪽 빨간 **테스트 +1천** 버튼 → 키가 오르고 "+1,000cm"가 떠오르며 몸이 커진다
- [ ] 2-3 **+10만**, **+1억**을 눌러도 발이 땅에 묻히거나 하늘로 튕기지 않는다
- [ ] 2-4 **+1경**을 여러 번 눌러도 몸이 어느 크기에서 멈춘다 (상한 12배)
- [ ] 2-5 커진 상태에서 걷기·점프·카메라 줌아웃이 자연스럽다
- [ ] 2-6 오른쪽 위 순위표에 "키" 칸이 있다
- [ ] 2-7 캐릭터 리셋(Esc → Reset)해도 크기가 그대로다
- [ ] 2-8 Publish(File → Publish to Roblox) 후 Home 탭 → Game Settings → Security → **Enable Studio Access to API Services** 켜기 → Play로 키 올리고 Stop → 다시 Play 했을 때 키가 남아 있다
- [ ] 2-9 (2-8 전에) API 접근을 안 켠 상태에선 "저장 불러오기 실패" 알림이 뜨고 게임은 정상 동작한다

## 3. 기본 맵 (한 번만, 맵이 새로 나오면 예전 BaseMap 지우고 다시)
- [ ] 3-1 Baseplate 게임에서 원래 있던 **Baseplate**와 **SpawnLocation**을 지운다 (Explorer에서 선택 → Delete)
- [ ] 3-2 프로젝트 폴더의 **`map/BaseMap.rbxm`** 을 스튜디오 화면으로 끌어다 놓는다 → Workspace 안에 BaseMap이 생긴다
- [ ] 3-3 Play 하면 양평역 앞에서 시작하고, 물맑은시장·남한강, 두물머리(강·느티나무·연꽃·돛배), 용문산 등산로, 정상(용문사·은행나무·구름)이 보인다
- [ ] 3-4 이제부터 맵은 서준이 마음대로 꾸며도 돼. 단, 이름 앞에 "Sensor"나 투명한 상자(FoodSpawn, ZoneArea 등)는 지우지 말고 위치만 옮기기

## 4. 성장 음식
- [ ] 4-1 맵 곳곳에 이름표 달린 동그란 음식(시장 우유/계란빵/호떡)이 있다
- [ ] 4-2 음식에 닿으면 사라지고 키가 오르며 "+N cm"가 뜬다. 8초 뒤 그 자리에 새 음식이 생긴다
- [ ] 4-3 가끔 반짝이는 금색 **황금 우유**가 나온다 (큰 보상)
- [ ] 4-4 Test 탭 → Clients and Servers → **2 Players** → Start. 두 캐릭터로 같은 음식에 동시에 닿아도 한 명만 키가 오른다
- [ ] 4-5 2·3구역 음식이 더 크고 보상이 크다 (테스트 버튼으로 키를 올려 가 보기)

## 5. 구역 문

- [ ] 5-3 운동장에 들어가면 모두에게 "○○님이 두물머리에 입장!" 알림, 화면 위 구역 이름이 바뀐다
- [ ] 5-4 키가 모자란데 벽을 점프로 넘거나 다리 옆으로 올라가도 되돌려지고 "아직 키가 부족해요!" 알림
- [ ] 5-5 **+10만** 후 용문산 등산로 문이 열리고, 등산로를 올라 정상에 갈 수 있다

- [ ] 6-2 비 10초 전에 "10초 뒤 ○○에 우유 비가 내려요!" 알림이 모두에게 뜬다

## 7. 철봉
- [ ] 7-1 철봉에 가까이 가면 "매달리기" 버튼(E키)이 뜨고, 누르면 **팔을 위로 뻗고** 철봉에 매달린다
- [ ] 7-1b 버틸 때마다(1초에 한 번) 턱걸이하듯 몸이 올라갔다 내려온다, 내려오면 팔이 원래대로
- [ ] 7-2 화면 아래 큰 "연타!" 버튼과 게이지가 뜬다. 스페이스(또는 버튼)를 빠르게 누르면 매초 키가 오른다
- [ ] 7-3 연타를 멈추면 "힘이 빠져서 떨어졌어요!" 하고 내려온다
- [ ] 7-4 스튜디오 Test → Device(폰 모양 아이콘)로 폰 화면을 켜고, 버튼 탭으로도 버틸 수 있다
- [ ] 7-5 매달린 채 Stop 하거나 다른 사람이 같은 철봉을 눌러도 오류가 없다 (한 철봉에 한 명)

## 8. 농구 (덩크)
- [ ] 8-1 골대 옆 주황 상자에서 "공 받기 / 내려놓기" → 손에 공이 붙는다 (한 번 더 누르면 내려놓기)
- [ ] 8-2 공을 든 채 림 아래에서 **점프** → 공이 림에 닿으면 "덩크!!" + 키 증가 (3초에 한 번)
- [ ] 8-3 서서 공을 림에 대기만 하면 골이 아니다 (공중에서만)
- [ ] 8-4 키가 작을 땐 겨우 닿고, 클수록 쉬워진다. 너무 높거나 낮으면 알려 줘
