# 스튜디오 확인 체크리스트

Claude는 로블록스를 직접 실행할 수 없어서, 여기 있는 건 서준이가 스튜디오에서 확인해 줘야 해.
안 되는 게 있으면 번호와 Output 창 빨간 글자를 같이 보내 줘.

## 1. 연결
- [ ] 1-1 Play 하면 Output에 "서버 시작", "클라 시작" 두 줄이 나온다

- [ ] 2-3 **+10만**, **+1억**을 눌러도 발이 땅에 묻히거나 하늘로 튕기지 않는다

- [ ] 21-13 보스전이 시작된 뒤 근처에 있으면 펫도 보스를 공격, 보스를 잡으면 보스 펫(미니 호떡 등)을 처음 한 번 받는다
- [ ] 21-14 나갔다 들어와도 펫 목록·레벨·팀이 그대로 (Studio에선 저장이 안 될 수 있음: 게시 후 확인)

## 22. 10cm 시작 · 건물 부수기 · 가게 생김새
- [ ] 22-1 새 계정(또는 환생 직후)은 10cm, 몸이 기본보다 확 작다(약 0.3배). 걷기·점프·카메라가 이상하지 않다
- [ ] 22-2 150cm에 가까워질수록 몸이 자연스럽게 커지고, 150cm에서 예전 기본 크기
- [ ] 22-3 테스트 +1천 정도로 키를 키운 뒤 2층 집 옆에 점프해서 착지 → 와르르(잔해·먼지·흔들림), 돌무더기, 키 보상
- [ ] 22-4 같은 자리 건물은 60초 뒤 다시 생긴다. 그 자리에 서 있으면 비킬 때까지 기다렸다 생긴다
- [ ] 22-5 키가 모자란 건물(예: 15층 아파트) 옆에 착지 → "건물 45m — 키가 더 커야 해요!" 안내만, 안 부서진다
- [ ] 22-6 한 번 착지에 최대 3채까지 부서진다. 양평역·정류장·시장 아케이드·로터리는 안 부서진다
- [ ] 22-7 오스타 코아루(114m)는 키 11,400cm 넘어야 부서지고, 이름판도 같이 사라졌다 같이 돌아온다
- [ ] 22-8 큰길 상가 1층: 글씨 간판 없이 노래방(분홍 네온·미러볼·마이크), PC방(파란 모니터 줄), 카페(컵·테이블·파라솔), 치킨(빨간 차양·닭다리), 편의점(초록·파랑 띠·진열대), 약국(초록 십자가), 미용실(줄무늬 기둥), 분식(빨간 등·솥), 학원(칠판), 꽃집(화분)이 보인다
- [ ] 22-9 시장 아케이드 간판도 글씨 대신 떡·과일·생선 같은 물건 모양

## 23. 코인 · 꾸미기 뽑기
- [ ] 23-1 오른쪽 위에 "코인 N". 몬스터 잡기·건물 부수기·보스·미션 완료 때 "+N 코인"이 떠오르며 오른다
- [ ] 23-2 왼쪽 **상점** 버튼 → 날개/오라/발자국 상자 3개, 확률·"전설까지 N번" 표시
- [ ] 23-3 코인 100 미만이면 "코인이 모자라요" 안내만. 100 이상이면 열기 → 빙글빙글 → 등급 색으로 아이템 이름
- [ ] 23-4 중복이면 "(중복 +50코인)"이고 코인이 50 돌아온다
- [ ] 23-5 같은 상자 30번째엔 전설 확정, "전설까지"가 다시 30으로. 전설이면 서버 전체 알림
- [ ] 23-6 처음 얻은 꾸미기는 자동 착용. 아래 탭에서 눌러 착용/해제
- [ ] 23-7 날개가 등 뒤에서 파닥이고, 오라 입자가 몸 주변에, 걸으면 발자국이 남았다 3초 뒤 사라진다 (전설은 빛남)
- [ ] 23-8 키가 커지면 날개·오라·발자국도 같이 커진다. 친구 화면에서도 내 꾸미기가 보인다
- [ ] 23-9 나갔다 들어와도 코인·보유·착용이 그대로 (Studio에선 저장이 안 될 수 있음)

## 24. 먹는 순간 · 커지는 순간
- [ ] 24-1 음식이 공이 아니라 우유팩·계란빵·호떡·옥수수·핫도그·한우 접시·비빔밥·은행·약수병·별빛 우유·별사탕·별똥별 조각 모양으로, 천천히 돌며 둥실
- [ ] 24-2 황금 우유는 금색으로 빛나는 우유팩, 우유 비도 작은 우유팩
- [ ] 24-3 먹으면 음식이 입으로 쏙 날아오며 작아지고, 부스러기가 톡, "냠" 소리
- [ ] 24-4 "+3cm 호떡"처럼 이름이 같이 뜬다
- [ ] 24-5 2초 안에 연달아 먹으면 "콤보 ×N", 소리가 점점 높아진다
- [ ] 24-6 몸이 툭 커지지 않고 부드럽게 커지며, 발밑 반짝이 + 카메라가 살짝 물러남
- [ ] 24-7 30cm·1m·2m·6m·12m·45m·114m… 를 넘으면 "키 1m 돌파! 강아지보다 커요!" 배너, 화면 번쩍, 충격파, 팡파레
- [ ] 24-8 접속하자마자 돌파 연출이 줄줄이 뜨지 않는다. 환생으로 줄어들 때도 안 뜬다
- [ ] 24-9 음식을 먹은 뒤 모양이 남아 있지 않고, 우유 비 때도 버벅이지 않는다
